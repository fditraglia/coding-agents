# coding-agents

A Quarto revealjs slideshow (`index.qmd`) about using AI coding agents (Claude Code, Codex) for academic productivity. Single self-contained HTML (`embed-resources: true`). Deployed via GitHub Pages at <https://ditraglia.com/coding-agents>.

## Workflow

1. Edit `index.qmd`.
2. `quarto render index.qmd` → produces `index.html` (self-contained, several MB).
3. `git add index.qmd index.html`, commit, push.
4. GitHub Pages serves automatically.

## Local-only working notes

The `notes/` folder is gitignored — for transcripts, source material, drafts. Nothing in there is public.
